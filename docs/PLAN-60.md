# 🏆 गणित गुरु — 60-दिन मैथ्स मास्टरी प्लान

**लक्ष्य:** 60 दिन में SSC (CGL/CHSL/MTS/GD/CPO/Selection Post) और Railway (ALP/NTPC/Group D/Technician/RPF) की पूरी गणित — concept clear + tricks + PYQ practice + trap-proofing — ताकि किसी भी सरकारी परीक्षा का maths section confidently crack हो सके।

> Website के तीन स्तम्भ: **📚 Learn (Day 1–60 mastery path)** → **🗂️ PYQ Bank (concept-wise tagged)** → **🔥 60-दिन Challenge (daily execution + spaced revision)**।

## 1. मास्टरी का सूत्र (हर concept के लिए)

हर concept को इस क्रम में पक्का करना है:

1. **समझ** — concept की definition + आसान हिंदी व्याख्या + ज़रूरी formulas (Learn पेज)।
2. **पहचान** — इस concept से *किस तरह* के PYQ आते हैं (concept-tags + signal words)।
3. **शॉर्टकट** — उस pattern की shortcut trick + जहाँ exam trap रखता है (⚠️ traps)।
4. **PYQ** — "🗂️ इस concept के PYQ" बटन से असली प्रश्न (exam • date • shift के साथ) — कम से कम 15–20।
5. **अभ्यास** — गलतियाँ एरर लॉग में; निष्कर्ष लिखें।
6. **ट्रैक** — concept को 👁️ समझा → ✍️ अभ्यास → 🏆 पक्का स्टेज तक ले जाएँ।

## 2. स्पेस्ड रिवीज़न नियम (1-3-7 व साप्ताहिक)

- **हर सीखने के दिन** शुरुआत में: *कल* पढ़े formulas बिना देखे बोलना (5–10 मिनट)।
- **D-3**: 3 दिन पुराने topic के 5 PYQ quick-fire।
- **D-7**: 7 दिन पुराने topic के flashcards + 1 trap।
- **शनिवार (Rev Day)**: पूरे हफ्ते का एकत्र दोहराव + मिश्रित क्विज़।
- **रविवार (Test Day)**: exam-mode टेस्ट + score analysis।
- Days 57–58: महा-रिवीज़न (अंकगणित + एडवांस्ड) — सिर्फ दोहराव, नया कुछ नहीं।
