Mistake & Accuracy Analytics

Mistakes, without invented accuracy

No candidate-performance data exists anywhere in this project. So there are no accuracy rates on this page — only error-sensitivity ratings (how easily a prepared student loses marks: setup complexity + trap density + reading load) from Master Report §5.2, the trap codebook, and scenario maths for negative marking.

HIGH sensitivity — setup-first drills

Data Interpretation, Mixture-Alligation, Trains, Pipes-Cisterns, Time-Work, Ages.

Practice: 10-item sets; first pass writes ONLY the setup (equation, frame, data mapping), second pass computes. Check after every item: units, signs, frame ("after n years" vs "n years ago", upstream vs downstream).

MEDIUM sensitivity

Percentage, Ratio-Proportion, Profit-Loss, Discount, TSD, Trigonometry, Geometry, Circles-Polygons, Mensuration 3D/2D, Algebra, CI, Boats-Streams, Sequences and Series.

Practice: mixed-model sets + trap-option drills — name the trap option before solving.

LOW sensitivity — speed sets

Number System, HCF-LCM, Simplification, Simple Interest.

Practice: formula-direct items, timed, accuracy focus. The risk here is careless slips under speed, not concept gaps.

Trap codebook (apply per model in every drill)

CodeWhat to check
sign errorPlus/minus flips, especially in pipes (fill vs empty) and signed quantities.
unit conversionkm/h ↔ m/s, minutes ↔ hours, cm ↔ m — convert before computing.
off-by-oneCounting, terms, days, "nth" items — check boundaries.
formula confusionSI vs CI, area vs volume, similar-looking identities.
trap optionThe near-miss answer the question is built around — name it first.
misreadQuestion frame or data misread — re-read the last line before solving.

No trap frequency is claimed for any topic — the schema has no trap field.
