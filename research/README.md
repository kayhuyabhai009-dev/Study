# Government Exam Mathematics — Research Platform (static website)

Pure HTML + CSS + JavaScript. No server, no PHP/MySQL, no build step, no CDN dependency
(fonts are progressive enhancement with system fallbacks).

## Run locally (recommended)

```bash
cd website
python3 -m http.server 8000
# open http://localhost:8000
```

Direct double-click on `index.html` mostly works, but some browsers block JSON `fetch`
from `file://` — the one-line server above is the canonical way.

## Host on GitHub Pages

Push the contents of `website/` to the repo root (or `docs/`) → Settings → Pages →
deploy from branch. No action, secret or build needed.

## Structure

- `index.html` — dashboard · `exams.html` / `exam.html` — examinations
- `library.html` / `paper.html` — 1,620-paper library, paper-level detail
- `important.html` — topic → concept-tag → every question from that concept
- `learn.html` — chapter → topic → concept with explanation, steps, fast method, questions
- `hierarchy.html` — 35 topics → 154 sub-topics → 295 concepts
- `patterns.html` · `formulas.html` · `compare.html` · `skills.html`
- `mistakes.html` · `cis.html` · `tracker.html` · `calendar.html` · `methodology.html`
- `css/` — tokens, base, layout, components, pages
- `js/` — chrome (shell + icons), data (loading + stores), charts (SVG),
  library (search/filters/marks), tracker (mastery + calendar), ui (palette, counters),
  render (page renderers)
- `data/` — generated JSON (see below)
- `data/questions_text/` — extracted question wording + options per paper
  (1,620 files, see `QUESTIONS_COVERAGE.md`); paper detail renders these.
  Options marked (+) are Muse-generated distractors (only where the paper's
  own options could not be recovered and the answer is numeric), never the
  paper's real options.

## Data

`data/` is generated by `../tools/build_data.py` from the project's frozen files
(final merged records, knowledge hierarchy, part-4 tables, aggregates, delivered
calendar). The script asserts: 1,620 papers, 40,894 records, 34,942 certain,
no question stem/options keys anywhere, and `papers_index.json` ≤ 500 KB.
Re-run it whenever the corpus unfreezes; the site itself needs no rebuild.

`data/questions_text/` is generated separately by `../tools/extract_questions.py`
from the 1,620 source PDFs (pdftotext → section slice → question split → option
parse → mapping to tag rows) and indexed by `../tools/build_questions_index.py`.
Coverage (v2.2, Nov 2026): 17,085 / 40,894 questions with recovered text
(41.8%); among them 15,432 with real options, 425 with (+) generated options,
1,228 with options still missing. See `QUESTIONS_COVERAGE.md` for per-paper
status, mapping mode and failure reasons.

Key honesty rules (see `methodology.html` on the site):
- Question wording/options in `data/questions_text/` come ONLY from the source
  PDFs (or, where marked (+), from perturbation of the numeric key answer).
  Unrecovered questions are listed as gaps, never invented.
- SSC + Railway 19 named exams only (18 record codes; NTPC Grad/UG share one code).
- Anything the data does not contain is shown as "Data unavailable", never invented.
- Report figures use the 34,917-certain base; live corpus is 34,942 / 1,620 papers.

## Progress storage

Mastery levels, calendar check-offs and library marks save in the browser's
localStorage only. Use Export/Import on the Tracker page to move progress to
another browser or computer.

## गणित गुरु (मुख्य website) के अंदर embedded mode

यह platform अब मुख्य website (`../index.html`) के **🔬 सरकारी एक्ज़ाम रिसर्च** सेक्शन
में iframe के रूप में चलती है। उस मोड में (`js/chrome.js`):

- `isEmbedded()` (`window.self !== window.top`) true हो तो sidebar/topbar/footer
  inject नहीं होते — body पर `gems-embedded` class आती है और CSS सिर्फ content दिखाता है।
- navigation मुख्य site के sub-tabs से होता है; platform के अंदर के लिंक iframe को
  navigate करते हैं (sub-tab highlight parent के `load` listener से होता है)।
- theme मुख्य site से आता है (`postMessage` → `gemsTheme`) — दोनों में एक रंग।
- डीप-लिंक: `important.html?topic=<slug>` और `learn.html?chapter=<topic>` सीधे
  उस topic/chapter पर खोलते हैं (मुख्य site के analysis cards से जुड़े हैं)।
- `data.js` में `unhandledrejection` guard है — fetch न मिले (file:// या किसी परीक्षा
  वातावरण में) तो भी "Data load nahi hua" बैनर दिखता है, page crash नहीं होता।

Standalone भी पूरी तरह चलती है: `research/index.html` सीधे खोलें (JSON fetch के लिए
local server ज़रूरी — file:// पर browsers fetch block करते हैं)।
